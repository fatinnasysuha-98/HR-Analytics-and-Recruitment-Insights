# HR Analytics and Recruitment Insights

This project analyzes candidate demographic, salary, education, and interview preference data using Python and Pandas.

## Project Objectives
- Analyze candidate age and salary trends
- Explore relationship between education and annual income
- Study candidate communication preferences
- Perform exploratory data analysis (EDA)
- Generate recruitment insights using Python

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Files Included
- recruitment_insights_analysis.ipynb
- DATABASE GMP.csv

## Key Analysis Performed
- Median age analysis
- Salary distribution analysis
- Education-level comparison
- Communication preference analysis
- Data visualization and insights
