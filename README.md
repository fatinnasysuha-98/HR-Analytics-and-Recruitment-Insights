# HR Analytics and Recruitment Insights

This project uses Python and data analysis techniques to explore candidate demographic information, salary trends, education background, and communication preferences during the recruitment process.

The analysis was conducted using Jupyter Notebook with Python libraries such as Pandas, NumPy, and Matplotlib to generate meaningful recruitment insights from the dataset.

## Project Objectives

- Analyze candidate age distribution
- Study the relationship between education level and annual income
- Explore communication channel preferences among candidates
- Perform exploratory data analysis (EDA)
- Generate HR and recruitment-related insights

## Dataset Information

The dataset contains candidate-related information such as:

- Age
- Gender
- Annual Income
- Education Level
- Preferred Communication Methods
- Mobile Device Usage
- Interview Communication Preferences

## Tools and Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Analysis Performed

### Median Age Analysis
Calculated the median age of candidates to understand the central age distribution among applicants.

### Education and Income Analysis
Explored how education levels may influence annual income trends among candidates.

### Communication Preference Analysis
Analyzed preferred communication channels such as:
- Email
- Phone Calls
- Video Calls
- Walk-In Interviews

### Device Usage Analysis
Examined the types of mobile devices commonly used by candidates.

## Findings and Insights

- Most candidates fall within a moderate working-age group.
- Candidates with higher education levels generally showed higher annual income trends.
- Email and mobile communication remain among the most preferred communication channels.
- Certain interview communication methods were more popular among candidates compared to others.

## Conclusion

This project demonstrates how Python can be used in HR analytics to analyze candidate data and generate recruitment insights. Through exploratory data analysis, the project provides a better understanding of candidate demographics, communication preferences, and salary-related trends.
